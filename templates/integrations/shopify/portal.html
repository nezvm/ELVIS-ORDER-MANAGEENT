Shopify Integration Instructions

Complete step-by-step guide to set up and use the Shopify integration.

1

How to Connect Your Store

  1. Go to your Shopify Admin → Settings → Apps and sales channels
  2. Click Develop apps (enable custom apps if asked)
  3. Create a new app and configure Admin API scopes:
    Required: read_orders, write_orders, read_customers, write_fulfillments, read_checkouts
  4. Install the app and copy the Admin API access token
  5. Paste it in the Connect Store tab and click Connect Store
  6. Click Verify API Permissions to confirm access
  7. Click Register Webhooks to set up real-time sync
[Screenshot Placeholder: Connect Store - showing API token entry and connect button]
2

How to Enable Webhooks

Use the Register Webhooks button in the Connect Store tab. This automatically registers:

  • orders/create → ERP creates order + lead
  • orders/updated → ERP updates order status
  • orders/paid → ERP confirms payment
  • orders/cancelled → ERP cancels order
  • customers/create → ERP creates lead
  • customers/update → ERP updates lead
  • fulfillments/create → ERP records fulfillment
  • fulfillments/update → ERP updates tracking

Manual webhook URL: {{ request.scheme }}://{{ request.get_host }}/webhooks/shopify/

3

How to Test the Integration

  1. Go to Test & Diagnostics tab
  2. Click "Test Get Shop Info" to verify API connectivity
  3. Use Webhook Simulator to paste a sample order payload and see how ERP would classify it (WEB_PAID or WEB_COD)
  4. Use Fulfillment Push Tester to test pushing tracking info to Shopify
  5. Click "Run Abandoned Sync Now" to fetch abandoned checkouts immediately
[Screenshot Placeholder: Test & Diagnostics - showing webhook simulator with result]
4

What Happens When Orders Arrive

  1. Shopify sends a webhook to ERP (orders/create or orders/paid)
  2. ERP validates the HMAC signature (if webhook secret is configured)
  3. ERP creates a ShopifyOrder record linked to the store
  4. ERP creates or updates a Lead with source = "Shopify Order"
  5. The order is classified as WEB_PAID or WEB_COD based on your sync rules
  6. If the customer matches an existing Lead, their record is updated
5

How COD Channel Split Works

Condition Result
financial_status = "paid" WEB_PAID
gateway contains "COD" or "Cash on Delivery" WEB_COD
Captured transaction exists WEB_PAID
No matching COD keyword WEB_PAID

Configure your COD keywords in the Sync Rules tab. Default keywords: COD, Cash on Delivery, cash_on_delivery

6

How Fulfillment Pushes Back to Shopify

  1. When an ERP order is marked as Shipped, the system automatically pushes fulfillment to Shopify
  2. It sends: tracking number, tracking URL, courier name
  3. Shopify marks the order as fulfilled and can notify the customer
  4. You can also manually test this from the Fulfillment Push Tester in Diagnostics
  5. Check the Outbound Logs to see push status for each order

Enable "Push Fulfillment on SHIPPED" in the Connectors tab to activate auto-push.

7

Abandoned Leads & Recovery Tracking

  1. The system polls Shopify for abandoned checkouts every {{ store.abandoned_sync_interval_minutes }} minutes
  2. Each abandoned checkout creates a Lead with source = "Shopify Abandoned Checkout"
  3. The lead includes: cart value, item summary, and recovery URL
  4. When the customer completes the purchase, the lead is automatically marked as RECOVERED
  5. View recovery stats in the Overview tab
