2

Generate System User Access Token

Create a permanent access token for API access:

  1. Go to Business Settings → System Users
  2. Click "Add" → Name it "ERP Integration" → Select "Admin" role
  3. Click "Assign Assets" → Select your WABA → Give "Full Control"
  4. Click "Generate New Token" → Select your WhatsApp App
  5. Enable permissions: whatsapp_business_messaging and whatsapp_business_management
  6. Set token expiry to "Never" → Generate and copy the token
Important: Copy the token immediately - it's shown only once!
3

Configure Webhook in Meta Developer Dashboard

Subscribe your app to receive WhatsApp messages:

  1. Go to Meta Developers → Your App
  2. Navigate to WhatsApp → Configuration
  3. In "Webhook" section, click "Edit"
  4. Enter these values:

    Callback URL: {{ webhook_url }}

    Verify Token: {{ verify_token }}

  5. Click "Verify and Save"
  6. In "Webhook Fields", click "Manage" → Subscribe to messages
