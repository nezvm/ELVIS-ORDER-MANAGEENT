How BSP Connection Works

1

Get BSP Credentials

Get your Phone Number ID and Access Token from your BSP dashboard

2

Configure Webhook

Set up webhook in your BSP to forward messages to Elvis ERP

3

Start Receiving Leads

Messages received on your WhatsApp will auto-create leads

1

Configure Webhook in Your BSP

In your BSP dashboard (e.g., Libromi, 360dialog, Wati), set up webhook forwarding with these details:

Webhook URL:
{{ webhook_url }}
Verify Token:
{{ verify_token }}
Subscribe to: messages
Note: The webhook format follows Meta's standard WhatsApp Cloud API format. Most BSPs forward webhooks in this exact format.
2

Register WhatsApp Number

From your BSP dashboard or Meta API Setup

WhatsApp Business Account ID (optional)

Required only for sending messages. Not needed for receiving leads.

3

Test the Connection

After registering, send a WhatsApp message to your business number. If configured correctly, the message will appear in the WhatsApp Leads section.
