How Lead Attribution Works

Organic Leads

Customers who message you directly without clicking an ad. Default for API-synced subscribers.

Ad Leads (CTWA)

Customers who click your Click-to-WhatsApp ads. Detected via webhook referral data or fbclid in message.

Important: Since you're using Wabis API sync (PULL), ad attribution is only captured when customers message through webhooks (PUSH). To track ad leads:

  1. Configure Wabis Out-bound Webhook
  2. Use Click-to-WhatsApp ads with proper tracking
  3. Or manually tag leads using Wabis Labels

Manual Source Tagging
