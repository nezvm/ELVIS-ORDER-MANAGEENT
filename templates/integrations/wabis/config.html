Get API Token

Get your API token from Wabis Developer Console:

  1. 1. Go to bot.wabis.in/api/developer/console
  2. 2. Login with your Wabis account
  3. 3. Copy the API Token shown at the top

Example format:

18091|phcZz1un2dBy...
2

Get Number IDs

Find the Number ID for each WhatsApp number in Wabis:

  1. 1. Go to Connect Account
  2. 2. Look for "Number ID" next to each number
  3. 3. Copy the Number ID (15-digit number)

⚠️ Use "Number ID", NOT "Business Account ID"

Example Number ID: 288969734293575

Multiple Numbers? Go to Numbers Page to set Number ID for each WhatsApp number

3

Setup Webhook (Optional)

For real-time updates, configure outbound webhook:

  1. 1. Go to Bot Manager → Out-bound Webhook
  2. 2. Click Create
  3. 3. Paste webhook URL below
  4. 4. Select trigger events
API sync works without webhook too
