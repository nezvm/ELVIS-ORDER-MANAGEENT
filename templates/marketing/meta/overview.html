Understanding Attribution in This Dashboard

Why deterministic campaign-level attribution is not available: WhatsApp Business Service Providers (BSP), including Wabis, do not forward fbclid, campaign IDs, or UTM parameters from Click-to-WhatsApp (CTWA) ads. The native WhatsApp deep-link passes the user directly to the chat thread, and the BSP receives only the phone number and message content — no ad attribution metadata.

What CAPI does: The Conversions API sends Lead and Purchase events (with hashed user data) to Meta so that Meta can: (1) optimize ad delivery using real conversion signals, (2) improve its own attribution models for reporting in Ads Manager. CAPI does NOT return campaign mapping back to the ERP.

How probabilistic attribution works: Each day, we compare the number of "conversations started" reported by Meta (from CTWA ads) to the total WhatsApp leads created in the ERP. The ratio (ads_share) determines whether each lead is tagged as "Probabilistic Ads" or "Organic". The confidence score equals the ads_share percentage. This is an estimate — use Meta's own Ads Manager for authoritative campaign-level ROAS.

Manual overrides: You can mark any lead as "Manual - Ads" or "Manual - Organic" from the lead detail page. Manual attributions are never overwritten by the nightly engine.
