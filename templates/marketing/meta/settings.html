Setup Guide

  1. Go to Meta Business Suite > Business Settings
  2. Create a System User with admin access
  3. Generate an Access Token with: ads_management, ads_read, business_management
  4. Copy your Ad Account ID from Ad Account Settings
  5. Copy your Pixel ID (or Dataset ID) from Events Manager
  6. Paste values here and click Save
  7. Click Test Meta Connection to verify
  8. Click Send Test Lead Event — check Events Manager > Test Events
